# 人狼推理ノート

iPhone Safariで使うことを想定した、人狼の推理補助PWAです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 参加者の名前を追加します。
3. 行をタップして、CO、状態、占い結果、メモを記録します。
4. 預言者COを登録すると、画面上部にその人の視点タブが出ます。
5. `エクスポート` で現在の卓をテキストとしてコピーできます。

## PWAとして確認する場合

サービスワーカーは `file://` では動かないため、PWA/オフライン確認にはローカルサーバーで開いてください。
URL例: `http://127.0.0.1:4177/index.html`
